# v4.5 双视角综合规则

生效入口：`annotate_videos.py --layout front-side` 或 `--layout side-front`。单视角及旧联合处理入口保留原实现；旧版规则另存 `SCORING_RULES_v4_4_legacy.md`。

## 1. 先匹配同一次动作

两个画面独立提取姿态、检测深蹲。使用原视频 PTS 秒数，不改变帧率，不按“第几次”硬配对。采用保持时间顺序的一对一动态规划，优先匹配有效动作对，再最小化时间与重叠代价。

默认最低点差不超过 0.4 秒，同时区间 IoU 不低于 0.25。单侧漏检不使后续编号错位。两侧都至少有 3 个候选而匹配比例低于较少侧的 50% 时停止融合，提示确认同步。未匹配候选高度重叠（IoU >=0.65、最低点差 <=0.65 秒）却不满足严格配对时，同样停止输出，避免随意丢弃异常证据或重复计次。这是输入一致性门控，不是“待复核”评分状态，也不是同步已被证明。

## 2. 一套边界和编号

每次匹配动作只产生一个综合编号。边界从证据更充分的检测视角选取，依次比较可用证据、原边界诊断、关节覆盖率、整体覆盖率及最大缺失间隔；同等条件优先侧面。保留两个视角各自的原始开始、最低点、结束时间及差异，不把投影不同的时间简单求平均。

相邻综合区间重叠时，在两个最低点之间的受支持重叠区间划分公共边界，并记录诊断。视频开头仍在下降或结尾仍在起身的边缘候选，不当作已完成深蹲评分：仅检查距端点不超过 2 帧的候选，以端点 0.18 秒内的肩髋运动估计是否仍在运动，阈值 0.2 投影腿长/秒。稳定结束的动作不会仅因靠近视频末端被删除。

## 3. 视角分工与质量门控

| 唯一项目 | 正面 | 侧面 |
|---|---|---|
| 回位完整性 completion | 可观测时参与 | 可观测时参与 |
| 可见踝点稳定性 foot_motion | 可观测时参与 | 可观测时参与 |
| 膝轨迹 knee_tracking_proxy | 参与 | 不参与 |
| 躯干侧偏 lateral_control | 参与 | 不参与 |
| 髋膝投影深度 depth | 不参与 | 参与 |
| 上升髋肩协调 hip_knee_coordination | 不参与 | 参与 |
| 躯干腿运动协调 trunk_control | 正面代理量，最高轻度 | 侧面可见运动依据 |
| 阶段匹配间接协调 indirect_control | 最高轻度 | 最高轻度 |

沿用 v4.4 关键点置信度 0.5、必要姿态覆盖率 90%、必要关节最大缺失 0.2 秒等门控；融合额外要求参与视角稳定且视角类型对应。没有可靠证据的项目为 UNAVAILABLE，不算通过、不自动扣分，显示已观测项目数。两侧共同项目记录双方证据，但只算一个项目。

## 4. 综合好中差

同一项目取可靠可观测证据中最高问题等级，保留来源与数值，不平均跨视角的不同几何量，也不把分视角等级做算术平均。

- 好 GOOD/3：至少有一个可靠观测项目，已观测项目全部 PASS。
- 中 MID/2：有 WARN，且没有任何受支持 FAIL。
- 差 POOR/1：存在受支持 FAIL。
- 没有任何可靠观测项：候选保留于诊断，不强行赋予质量等级，不产生“待复核”类别。

间接线索最高 WARN；多个 WARN 不叠加成 FAIL。一个视角的 PASS 不抵消另一个视角清楚观测到的异常。缺失视角不会凭空造成中或差，但 GOOD 必须连同已观测项数解释，例如 6/8 不代表未观测的两项正常。

## 5. 原评分阈值

| 项目 | WARN | FAIL |
|---|---:|---:|
| 返回髋高误差 / 本次幅度 | 0.20 | 0.40 |
| 踝点位移 / 投影腿长 | 0.12 | 0.20 |
| 正面膝内移变化 / 投影腿长 | 0.10 | 0.20 |
| 正面躯干侧偏投影等效角 | 12 度 | 25 度 |
| 侧面深度不足 / 大腿投影长度 | 0.10 | 0.40 |
| 侧面髋肩上升失配 / 投影腿长 | 0.08 | 0.16 |

其他线索仍按原 `grading_config.json` 计算，模型与阈值哈希见 `reference_parameters.json`。例如，正面通过、侧面深度触发 WARN 时，综合仍为中；这并不表示正面存在问题，也不等同专家对整体动作的结论。单纯前倾、躯干缩短、髋或膝先动本身不自动扣分。

## 6. 视频标注及可追溯性

两幅画面分别绘制骨架，均显示相同 `OVERALL`、综合动作编号、DOWN/UP 阶段、综合区间、观测项数和异常来源。第二行分视角 evidence 仅解释证据。开始、最低点、结束附近显示标记；每一帧均输出区间/阶段标签，底部停顿没有单独新增阶段。

保留每个源视频帧、显示尺寸和 PTS，输出后重新解码验证帧数、时间轴。仅编码带标签的副本，无音频。本流程不加载传感器 CSV，因而不改变采样率、采样点、时间戳、传感器值或已有视频—数据对齐关系。

骨盆倾角、腰椎曲度、脚跟接触、负重大小及双脚负荷分配不在自动结论范围内。参数是可配置工程规则，尚无独立专家标定准确率。
