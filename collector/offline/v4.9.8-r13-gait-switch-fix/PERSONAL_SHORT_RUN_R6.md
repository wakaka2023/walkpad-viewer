# r6：短慢跑的同人相对判别

## 为什么补这一分支

r5 的短跑规则通过一串交替脚踝极值与躯干反弹确认连续跑动；短慢跑、加速或减速时，某一步间隔较长可能使整串不成立。r6 保留原规则，另对「看见运动但走跑未定」的帧进行保守复核，不改动人体过滤、跟踪、重入、显示编号、权重和深蹲识别。

## 数据与判别

1. 只使用同一分析片段中可用的交替脚踝极值；用相邻极值时间中点界定步窗口，不用预设多少秒的分类窗口，也不要求原来的连续四峰规则匹配到候选步。
2. 用已支持的走路步和已由 r5 短跑反弹规则支持的跑步步作参考；各至少两步。脚踝、肩、髋、肘、腕必须有效。窗口内及与前一步的移动方向不得反向；髋、肩去除线性投影变化后应有同向起伏。
3. 每一步计算两脚踝图像距离的 90 分位数、髋肩两组峰谷幅度的较小者（都按本人投影躯干尺度归一），以及相对更屈肘一侧的余弦中位数。腿部展开和躯干同步起伏都须更接近本人跑步中位数，而不是本人走路中位数；屈肘须比本段走路参考更明显。
4. 只更新步窗口里原为 `gait_type_unresolved` 的实测帧。`frame_labels.csv` 的 `activity=running`，但 `activity_status=candidate`，`annotation=跑步候选`，证据为 `personal_short_running_candidate`。不扩张到前后明确动作，也不回填原轨迹中断。

## 边界与限制

- 新增分类不拿固定步频、速度或固定步间隔作走跑分界。既有脚踝候选提取、姿态质量门槛和原走跑规则仍有数值参数；不是全包移除了所有门槛。
- 没有可信的同人走/跑参考、脚踝或手臂不清楚、或者证据相互矛盾时，保留原结果。不能保证任意新镜头均能补判；这条需要投影方向一致的地面移动证据，不是跑步机专用修订。
- 图像关节轨迹和屈肘不等同于足底触地测量。短段故显示「候选」，不声称测出了离地和精确落地时点。
