# Squat pipeline v4.4: visible motion and indirect coordination cues

本包包含正面和侧面的检测、评分、视频导出代码，以及姿态权重和完整参数。包版本为 v4.4，评分版本为 `observable-video-foot-v4.4`。在 v4.3 的五项可见指标上新增一项“分阶段躯干与腿部协调线索”。深蹲区间算法仍为 v4.2.0；`final_parameters.json`、检测规则和模型权重保持原样。完整规则与解释见 `SCORING_RULES.md`。

## 评分依据

每次深蹲独立评分，不使用文件名、错误动作名称、固定次数、人工指定时间或其他重复动作的排名。评分使用当前视角下可观察的二维运动指标。

| 视角 | 原五项指标 | 新增第六项 |
|---|---|---|
| 正面 | 是否回到起始髋高、可见踝点位移、膝宽相对踝宽的内移变化、躯干横向偏移变化、躯干与腿部的持续运动失配 | 起始参照归一化的躯干/小腿垂直投影，在动作阶段及匹配腿部姿态下的变化 |
| 侧面 | 是否回到起始髋高、可见踝点位移、髋膝投影深度、上升时髋肩运动协调、躯干与腿部的持续运动失配 | 肩髋连线投影角，在动作阶段及匹配腿部姿态下的变化，并要求膝部运动支持阶段判断 |

正面横向变化使用起始躯干投影高度作固定归一化参照，避免大幅前倾导致躯干投影缩短后，被误认为巨大侧倾。静态前倾幅度、躯干缩短、髋或膝单纯先动本身不会自动扣分。正面躯干运动失配最高作为轻度问题，避免用正面投影推断侧面腰部状态。

新增四类线索：腿部尚未明显下降时躯干已大幅折叠；腿部高度基本恢复而躯干仍未恢复；底部腿部基本不动时躯干继续折叠；相近腿部姿态下上升比下降有更多躯干折叠。所有线索必须持续存在、关键点覆盖充分，并记录实际证据区间、数值、阈值及参照帧。间接线索最高只判 MID，不自动命名为“骨盆后倾”或“腰部塌陷”。

| 标签 | 含义 |
|---|---|
| GOOD / 3 | 当前视角适用的六项筛查指标均可观察且未触发规则；不代表所有解剖学姿势正常 |
| MID / 2 | 存在间接协调线索、轻度可见问题，或者实际姿态覆盖不足、视角不稳定、必要关键点缺失 |
| POOR / 1 | 存在规则支持的严重问题 |

每次输出 `observable_criteria_json`，列出各项数值、阈值、PASS/WARN/FAIL/UNAVAILABLE。`grade_provisional` 标识观测不足；缺少可选 IMU 不会导致降为 MID。

骨盆倾斜、腰椎曲度、脚跟接触和双脚负荷分配不属于自动评分项目。GOOD 仅表示当前视角的可见指标通过，不证明这些不可观察的解剖学项目正常。即使原视频以“骨盆后倾”或“腰部塌陷”命名，也不会按照名称强制给出 POOR。可选人工复核表仍可补充明确观察到的问题。

## 视频批处理

在包含本 README 的目录执行；使用已有 Python 环境并安装 `requirements.txt` 所列依赖。Windows 推荐命令：

```powershell
python annotate_videos.py "C:\data\videos" --recursive --output "results\video_scores_v4_4" --device 0
```

默认自动识别正面/侧面、生成区间、计算可见指标并输出评分视频。支持 `.mp4`、`.qt`、`.mov`、`.mkv`、`.avi`、`.m4v`。输出使用新的目录。已有同名文件的视频应分开处理。

- `--view front` / `--view side`：明确相机视角。
- `--device cpu`：使用 CPU；`--device 0` 使用首个 CUDA 设备。
- `--no-preview`：跳过视频编码，保留标签和评分表。
- `--labels-only`：仅生成原区间/阶段标签，不评分。
- `--grading-config custom.json`：覆盖评分配置中的部分字段。
- `--config final_parameters.json`：指定完整的区间参数文件。

每个视频输出到 `<output>/<video_stem>/`：

| 文件 | 内容 |
|---|---|
| `review.mp4` | 全长视频，叠加次数、阶段、分级和评分依据；实际线索发生时显示 ACTIVE CUE 和紫色肩髋线 |
| `intervals.csv` | 原视频起止帧和 PTS 时间、边界诊断 |
| `frame_labels.csv` | 逐原始帧区间/动作标签 |
| `frame_candidate_grades.csv` | 原逐帧标签追加评分，不改原字段 |
| `activities.csv` | 深蹲、站立、走动、跳跃等候选区间 |
| `keypoints.npz` / `metadata.json` | 姿态缓存、输入和配置记录 |
| `grading/rep_metrics_and_grades.csv` | 逐次可见指标、分项状态和评分原因 |
| `grading/video_indirect_evidence.csv` | 每个触发线索的时间、测量值、阈值、证据帧和参照帧 |
| `grading/grading_audit.json` | 算法、阈值和评分范围审计 |
| `grading/review.html` | 点击评分行播放动作，点击线索按钮播放实际证据区间 |
| `grading/video_review_template.csv` | 可选人工复核表 |

预览保留原始分辨率、帧数及 PTS 时间轴，时间量化误差不超过 1/90000 秒；视频不含音频。

## 视频和双脚 IMU 联合处理

```powershell
python run.py --video "C:\data\video.mp4" --data "C:\data\data.txt" --output "results\paired_run"
```

也可以修改 `run_local.py` 的 `VIDEO_PATH`、`DATA_PATH` 和输出位置后运行。模型随包提供。完整入口还支持 `--video-config`、`--grading-config`、`--video-review`、`--no-preview`、`--resume`。首次使用本版应新建输出目录，之后再使用经过输入/推理配置校验的缓存。

保留四项脚部指标及预处理公式：角速度向量 RMS、角加速度向量 RMS、加速度模长 SD、左右角速度 RMS 绝对差。仅使用双脚六轴信号，不使用手腕信号或设备欧拉角。

四项指标用于补充与可见运动事件同时发生的脚部运动证据；保留事件局部对比、多指标支持及正负 0.1 秒平移敏感性检查。单纯运动强度高、左右 RMS 不同不会自动判差，也不按“越小越好”评分。左右 RMS 差不代表左右负荷差。

联合模式输出另包含 `data/feet_50hz_unlabeled.csv`、`data/feet_50hz_candidate_labels.csv`、`data/rep_boundaries_candidate.csv`、`data/feet_50hz_candidate_grades.csv`、`data/native_feet_preserved.tsv` 等。保留原字段、源行号及未评分数据。`grading_basis` 区分 `VIDEO_ONLY` 和 `VIDEO_PLUS_IMU`。

默认 `common-start` 假设首视频帧和双脚首样本同时开始；这并非已经验证的同步。没有共同起点依据时使用 `--sync-mode unmapped`。不恢复未知丢包位置。

## 参数与适用范围

`final_parameters.json` 保持原 v4.2.0 字节内容，因此其中版本号仍是 v4.2.0。它控制区间选择，不代表本包评分未升级。`grading_config.json` 控制新版评分，`reference_parameters.json` 保存权重和参数 SHA256。

主要默认值如下；完整生效值会复制到每次输出的 `grading_config_used.json`。

| 项目 | 轻度 / 严重阈值 |
|---|---|
| 返回起始髋高误差 / 本次髋高幅度 | 0.20 / 0.40 |
| 可见踝点位移 / 腿长 | 0.12 / 0.20 |
| 正面膝内移变化 / 腿长 | 0.10 / 0.20 |
| 正面躯干横向偏移的投影等效角 | 12 / 25 度 |
| 侧面投影深度不足 / 大腿投影长度 | 0.10 / 0.40 |
| 侧面上升髋肩位移失配 / 腿长 | 0.08 / 0.16 |

必要姿态覆盖率至少 90%，最大连续缺失 0.2 秒。侧面可使用一条清晰可见腿；正面双侧指标要求双侧点可见。视角不稳定或真正缺失关键观察时仍会保留不确定状态。

新增线索的持续时间为 `max(0.18, min(0.35, 0.08 × 本次时长))` 秒。正面近站立阶段要求躯干与小腿联合投影比例不超过 0.55；侧面要求相对起始躯干倾角增加至少 20°。匹配腿部姿态的额外变化阈值分别为起始躯干投影的 0.20 和侧面投影角 15°，并要求髋、膝相对踝的位置误差均不超过腿长 0.05。完整前置条件见 `SCORING_RULES.md`。

这些是可配置的工程规则，尚未用独立专家评分标定，不应解释为临床关节角度或全面动作质量量表。相机透视、遮挡和姿态估计误差仍影响结果。边界标签和分级均为自动候选结果。
