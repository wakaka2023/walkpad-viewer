# v4.9.7 多人动作标注

同一视频中的每个 YOLO 轨迹 ID 独立提取姿态、校准动作特征、判断动作、找边界并记录深蹲计数。两人在同一帧可以显示不同动作；两人同时深蹲时，各有各的下降、回升、起止时间和次数。默认跟踪配置是 `bytetrack_actions.yaml`（ByteTrack），另有保守的离线短轨迹重连；并非 BoT-SORT + ReID。轨迹 ID 在当前视频内有意义；严重遮挡或离开画面太久可能重新编号。重连后的不同原始 ID 仍分片分析，不把动作边界跨缺失轨迹拼接。

仅输出 **站立、走路、跑步、深蹲、上楼梯、下楼梯**，各可显示候选；多种证据冲突可并列候选。缺少可用证据时为其他。手部运动不作为主类别。深蹲的下降、回升、组内回位是附加阶段，不用于其他动作。

- **深蹲**：保留原高可信周期，并用本人髋到足的下沉和回升、观察到的膝屈伸、相对脚部稳定性和个人轨迹的噪声水平补足浅深蹲。补检不要求先有两次旧规则识别；更不借用其他人的动作或次数。仅躯干缩短不能计次。对低置信或遮挡姿态不会硬补一个周期。
- **走路、跑步**：跑步机等原地步态看双脚交替时的髋和肩相位；地面移动额外分析补偿镜头后的躯干位移、腿交替频率与规律性、髋部上下的相对振幅。比较同一 ID 同段轨迹的步态证据，用本人在视频里的静止姿态估计位移和腿部活动的噪声；短窗口内也检查交替摆腿之间两只脚踝是否短时近乎稳定，以及髋是否随步态明显上下起伏。走跑不以统一的速度、步频或髋部起伏数值分界。短时相位缺失可用同一人相容的相邻步态补齐；只有走跑转换或两套证据冲突才并列候选。CSV 保留用到的节奏、髋起伏和上下文推断依据；2D 脚踝代理并非直接的足底接触测量。
- **上下楼梯**：先用方向一致的交替落脚与髋肩高差定位阶梯，再用同一轨迹上可见的躯干移动连接跨步和短暂停顿。上下方向不同，转向、上下端平地不跨过。如同一轨迹已建立楼梯进出口，有两段分开的同向落脚证据，且髋、肩均沿该路径到达下一楼面，可以确认完整行程。缺少进出口或方向证据时保留候选。
- **参数**：`action_config.json` 中还包含兼容 v4.7 单人入口的旧参数及保守验收规则。实现仍有可见比例、最短可观察时长、相对噪声倍数和旧版候选提取参数。本版避免用统一的速度或步频数值划分走跑；深蹲补检不使用统一峰值膝角切分。静止基线来自本人在视频里的可用片段，无需另拍校准动作；基线不足时仍可用可见的动作形态。


v4.9.5 移除了多人走路复核中的统一画面位移速度、水平及竖直位移和腿速门槛。补偿镜头后的位移与腿部活动和此 ID 的静止参考比较；没有足够静止帧时，用该轨迹中波动较小的样本估计信号底噪。持续移动不是走路成立的硬条件：转身或投影速度短暂缺失时，两侧都有走路证据且中间可观察到双脚交替，允许用该人的局部步时补齐；表中保留 `walking_turn_context`。脚出画、停止迈步、轨迹丢失和明确跑步证据仍能阻止这类补齐。仍有跟踪质量、最短采样窗、时间拼接和旧规则候选生成参数；这并不意味着包里的全部动作规则都没有数值参数。

v4.9.6 增加对短走和转身的支持：检查相继两次支撑交替，两脚落点在共同前进方向上的推进是否超过该段姿态点的抖动。不同速度的人转身时，无需达到统一的位移速度。证据不得跨实际轨迹中断、深蹲或明确跑步。

v4.9.7 增加只拍到腿脚时的分支：绑定到独立轨迹，用地面纹理估计相邻帧间的镜头运动，再看补偿后的腿部摆动、局部周期和足部相对地面的短暂停驻。走跑不以画面位移的快慢划分。双脚可分辨、在多个步态周期可观察到两脚相对地面同时稳定，且中间还有支撑证据时，才把相容的步态标成正式走路；缺少此类证据时保留候选。纯镜头晃动不能作为走路依据，地面纹理不足会限制识别。`cropped_ground_observation` 与 `context_inferred` 分别记录局部观测和连续性推断。

仅在近景裁切轨迹有框重叠、多次可见关节重合，且第二轨迹缺少独立支撑时，剔除重影 ID。极短漏检通过同一原始 ID 两端、持续地面步态证据和没有其他人交叠等条件核对后，可用 `image_supported_continuation` 标明位置插值；它不是 YOLO 实测。`metadata.json` 记录进入该分支的 ID、去掉的重复 ID 及插值帧数。

## 运行

```shell
python -m pip install -r requirements.txt
python recognize_multi_actions.py "input.mp4" --output "output" --device auto
```

带 NVIDIA 显卡时 `--device 0`；画面需要额外顺时针修正时加 `--rotate 90`。竖屏运行示例：

```shell
python recognize_multi_actions.py "飞书20261119-161238.mp4" --output "output" --device 0 --rotate 90
```

默认读取 `models/yolo26s-pose.pt` 和内置跟踪参数。Linux 如字体未自动找到，指定 `--font /usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`；Windows 可指定 `--font C:/Windows/Fonts/msyh.ttc`。同一输出路径再次处理需加 `--resume`。发布时用 Python 3.11 / Ultralytics 8.4.211；CUDA 版 PyTorch 要与本机驱动匹配。

输出 `review.mp4`、`activities.csv`（逐人连续区间）、`action_events.csv`（逐人单次深蹲）、`frame_labels.csv`（每帧每 ID）、`gait_regimes.csv`（步态证据）、`track_id_map.csv`（原始跟踪与输出 ID 的映射）和媒体校验记录。区间为相对原始首帧 PTS 的 `[start,end)`，逐帧从 1 编号。重复编号以单个 ID 为范围，不能只按 `event_id` 跨人连接。`context_inferred` 区分部分上下文判读。`raw_*` 是旧规则审计数据，最终标签取非 `raw_*` 文件。

```shell
python -m unittest discover -s tests -q
python -m unittest discover -s tests/video -q
```

五段随附的视频是开发与回归样本；核对位置、结果及局限见 `VALIDATION.md`。公开外部验证可采用 Reznick 等的 *Lower-limb kinematics and kinetics during continuously varying human locomotion*（Scientific Data，2021），其中走、跑和变换步态的参考数据适合检查不同人的步态判别。动捕数据不能替代真实 RGB 视频中的遮挡与多人跟踪测试；本包没有用公开数据训练或报告独立准确率。

### r3：短时“其他”连续性修订

- 只在同人、同一轨迹片段、全程真实跟踪且躯干可见时考虑。两侧同一持续类动作（站立、走路、跑步或同方向楼梯），两侧直接证据各至少 0.35 秒、中央纯未知最多 0.60 秒，才允许推断。
- 走路另设较窄的规则：中间至多 0.30 秒，且每帧均有身体运动但步态未分型；一侧有至少 0.35 秒直接走路证据，另一侧至少 0.22 秒仅为步行候选（有平移和步动证据，无其他动作候选）。
- 不覆盖已有明确动作、弯腰、深蹲事件或真实的跟踪断线，不增加深蹲次数。成片显示“推断”，逐帧表保留 `raw_activity` 并附 `context_bridge_reason`；这是上下文推断，不是直接观测。原模型权重、身份和跟踪逻辑不变。

### r4：有固定顶部字幕条的腿脚近景

- 先用腿部关键点可信、上半身关键点长期缺失、人体框占比较大筛选疑似近景。仅有疑似近景而旧入口未命中时，才采样源视频找固定顶部条；要求多数采样帧的近均匀区域与下方有效画面有一致的横向边界，不识别、读取或使用字幕内容。
- 确认顶部条后，裁身判定相对其下方的有效画面边缘；沿用原版检测框、姿态缓存和跟踪 ID，不裁切交付视频。未确认顶部条则保留旧入口。注册地面运动时排除顶部条。
- 仅新分流的腿脚轨迹可用 0.90×常规关键点阈值寻找鞋周图像点（默认 0.45）。仍须由地面补偿后的鞋周运动、反复支撑和腿部节律支持走路，由双脚相对地面静止支持站立；证据不足不直接定类。短时图像支持的跟踪衔接继续标记为推断。
- `metadata.json` 记录 `cropped_content_top_px` 与 `cropped_banner_tracks`。适用一般固定顶部条，不包含特定文件名、动作时间、字幕词或固定动作顺序。


### r5：人体证据不足的候选不编号

1. 检测框和原始追踪编号只是候选。原本只要观测时长、帧数达标，动作即使未知也能分配显示 ID；r5 在已有可选的镜面区域过滤之后、短断轨合并和衣着重入之前，增加人体证据核验。不改检测器权重、跟踪阈值或动作判别规则。
2. 关键点须置信度达 `keypoint_conf`（默认 0.50）、坐标有效且在框附近。需符合框尺度下的人体骨段连接：躯干加相连的肢体或头/肩证据，或具有头、双肩、手臂证据的上身。纯检测框、孤立脚踝点或集中成一团的点不能单独确认。对贴近顶部、占比较大且上身不可见的裁切人体，允许用双膝或带小腿连接的多个下肢点确认，不要求全身入镜。
3. 一条原始轨迹至少要有 3 次有效观测，首尾间隔至少 `person_pose_confirm_s`（0.08 秒），相邻有效观测间隔不超过 `person_pose_max_sample_gap_s`（0.19 秒）。均按源视频时间戳计算，轨迹自动评估，不用动作时间或文件名。不要求移动；短时遮挡和有可用局部证据的观测可在已确认轨迹中保留。连续至少 3 个缺少局部证据的观测、覆盖达到 `person_unsupported_span_s`（0.90 秒）时，移除这段无支持的检测框；原始候选与时轴仍保留在缓存中。
4. 没通过人体核验的整个候选轨迹不上画面、不参与身份重连，也不占用编号。通过此关后，仍应用 r4 原有有效轨迹、动作和首次入镜编号规则。`person_evidence.csv` 可审计；`track_id_map.csv` 的 `rejected_person_evidence` 只表示人体证据不足，不是对物体类别的判断。
5. 如果物体或镜像能持续产生可信人体骨架，不能靠这道规则保证排除；已知固定镜面可继续用 `--ignore-static-roi`。很小、严重遮挡或只有鞋子可见的真人也可能因证据不足没有 ID。已烧录在源视频像素里的框和 ID 不会被抹掉。


## v4.9.8-r6：同人短慢跑候选

只对原步态未定帧进行补判；用同一分析片段已有的走、跑参考，比较投影腿部展开与髋肩同步起伏，并以超过本人走路参考的屈肘作为佐证。新增分支不用统一速度、步频或步间隔分界，不覆盖明确走路和转身。参考或可见关键点不足时回退到 r5。详见 `PERSONAL_SHORT_RUN_R6.md`。


## v4.9.8-r7：静态平面人像

人体姿态验证通过不等于真人。对画面内符合条件的小型、稳定轨迹，比对墙面配准、闭合纸面边界和内部纹理是否有独立运动；三项同时支持才在编号前删除，不改动作阈值。见 `FLAT_DEPICTION_R7.md`。
