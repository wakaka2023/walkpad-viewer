# v4.9.8-r9：跑步转向（过渡）

r9 保留 r8 的检测、人体筛选、重识别、动作计次及走跑判别。在 r8 步态形态判别之后、动作时间线整理之前，额外检查同一个实测轨迹上的「跑步—弱走路—跑步」。

- 仅检查原步态证据是“有步动但走跑未定”的走路段。不覆盖独立步态证据支持的走路、站立、楼梯、深蹲或事件。两侧各需有足够时长的直接跑步证据；用该人两侧的局部步周期限定邻域和过渡的检查范围，不用固定秒数、步频或速度直接区分走跑。
- 以背景相机变换补偿髋中心和双脚中点轨迹。同一段内，两种轨迹需同时显示跑步方向折返，折返点需位于候选段内，且净位移要超过各自邻域的跟踪抖动。有跟踪缺口、足点不可见、背景变换失效、仅相机动或只有某一种轨迹反向时，不改判。
- `running_turn` 显示为“跑步转向（过渡）”，状态 `transition`，不计作确认走路或匀速跑。逐帧表记录 `pre_turn_activity`、`pre_turn_gait_evidence`、`turn_pivot_video_s` 和 `turn_reference_step_s`。时间段是自动识别结果，不是接触或步相实测。几乎只沿视线移动、转向证据不可见时，可能不触发。

## 验证

- `1ffe405bdda198b6aed5df6a0b860ee2` ID 1：2.267–5.767 秒跑步；5.767–6.667 秒“跑步转向（过渡）”（27 帧，折返证据约 6.20 秒）；6.667–10.667 秒跑步。未改变其它帧的动作标注。成片 383 帧，PTS 与源一致，原音频包一致。
- 其余五段用同一规则和原缓存重新分析，无动作标注差异，包括无人片仍为 0 个 ID。六段跟踪、相机缓存、ID 映射和动作事件表与 r8 字节一致。
- 合成测试覆盖不同帧率/步周期、独立走路、站立、较长走路、无折返、观察中断、相机失效、仅髋反向及相机造成的表观折返。目标片是修正案例；其余五段是回归，非新视频准确率评估。
