# v4.9.8-r13：转身、裁切步态与连续性

本版只改多人标注的动作判别和候选逻辑。沿用 r12 权重、跟踪、身份编号、镜面/照片过滤和原有参数。新规则不读取文件名、预设时间点、固定人物 ID 或固定镜面区域。

- **原地转身**：同一轨迹中，肩与髋的有向投影一起变化，脚相对背景重新落位且身体净位移不足以解释为连续走路。用片段噪声、前后短时稳定姿态和可见像素分辨率排除抖动、只转头/扭肩及相机平移。和普通走路、跑步折返、深蹲分别处理。
- **步态中的断点**：同轨的同类可靠步态可以提供本人的步态相位参考；只有断点内实测双腿运动也吻合才补作候选。短停、丢轨、不同类别证据或已确认深蹲不靠插值覆盖。不会把走路与跑步按一个固定步频、步间隔或速度切开。相对周期范围是观测连续性的保护，不是走跑分界。
- **近镜头裁切**：可见双腿仍有一致的交替运动，或相机补偿后三处身体尺度仍沿邻近动作的方向推进时，仅补候选。近镜头出现跨前/后视角的真实换向并由同轨步态夹住时，将转向列为候选，而不是硬填成持续走或持续跑。视野不足或真实停顿仍可能显示「其他」。
- **审计**：`pre_pivot_activity`、`activity_reason`、`context_bridge_reason` 记录证据；`activities.csv` 与 `frame_labels.csv` 保留候选状态；深蹲确认事件查看 `action_events.csv`。帧间区间以左闭右开输出。

默认参数仍见 `action_config.json`。这里的转身是单目投影推断，不是三维身体角度估计；遮挡、极端机位、姿态关键点颠倒或无连续轨迹时无法保证恢复。14 段属于本次回归对比，不是陌生摄像场景的独立准确率验证。
