# v4.9.8-r8：地面和跑步机走跑修正

## 判别规则

- 对同一个人的同一跟踪片段，拟合双脚相对骨盆的反向周期。髋和肩的共同竖直分量必须超过局部噪声，才用作回弹证据；将它和该人的摆腿幅度、本片段中的姿态相位一起对照。优先用较短观察窗；慢步态需要更多时间观察到周期时才使用长窗。步间隔只用于定位相位和衡量动作连续性，不直接以某个步频、速度或秒值来划分走与跑。
- 用片段内数据拟合相对形态模式；旧规则给出已观察到的走跑线索，r8 用相位和个人噪声包络复核，证据不足时保留既有结果或“其他”。因此本版不是完全没有固定参数：姿态质量门槛、观察窗及旧规则的后备分支仍在。没有按文件名、设备类型或指定时刻切换类别。
- 在同一 ID 上，如果“其他”只是短暂未分出走跑，两侧都是同一动作且仍有可靠跟踪，则可按该人相邻实测步周期补齐。跑步中回弹强弱短暂变化但腿与躯干的周期、相位仍一致时，也保留连续跑步。推断写入逐帧记录，不增加深蹲次数，也不填真实站立、明确的另一动作或跟踪丢失。
- 不改变姿态权重、人物/照片过滤、ID 回连或计次规则。此方法使用投影姿态，不宣称逐帧测出了脚底接触或空中期。严重裁切、遮挡、转向及陌生视角仍可能需要复核。

## 使用

沿用原入口和参数：`python recognize_multi_actions.py INPUT.mp4 --output OUTPUT --device 0`。读取模型目录内原 r7 权重。`frame_labels.csv` 的 `pre_cycle_gait_activity`、`pre_cycle_gait_evidence` 记录改判前的分支；`personal_gait_step_period_s` 与 `personal_gait_recoil_leg_ratio` 是同人周期复核的数据；`context_bridge_reason`、`gait_inferred` 区分连续性推断。

## 验证范围

这次使用六条原视频回归，其中指出问题的两条用于开发验收，不是独立的泛化测试。保留以“其他”表示的低证据段，不把所有未分类帧强行填成走路或跑步。
